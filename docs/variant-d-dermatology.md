- **프리미엄 · 클린 · 세련된** — 고급 스킨케어 브랜드 같은 톤

### 디자인 원칙
- 여백 넉넉하게 — 섹션 py-28~32, 요소 간 간격 충분
- 부드러운 라운드 코너: `rounded-2xl` ~ `rounded-3xl`
- 퍼플 + 골드 조합으로 프리미엄 느낌
- 시술 데이터/순위에 골드 사용
- 애니메이션: 부드러운 fade-in, subtle scale, 절제된 사용
- 이미지 비중 높게 (시술 관련 아이콘, 일러스트)

### 6. FAQ 섹션

**배경**: zinc-50

**타이틀**: 피부과 원장님이 자주 묻는 질문

**Q1: 피부과 시술 중 외국인이 가장 많이 찾는 시술은 무엇인가요?**
```
레이저 토닝/리프팅이 가장 높은 관심도를 보이며,
보톡스, 필러, 리프팅, 스킨부스터 순으로 수요가 높습니다.
특히 중국·일본 환자의 레이저 시술 수요가 두드러집니다.
```

**Q2: 피부과 시술 용어도 정확하게 번역되나요?**
```
의료 전문 용어에 최적화된 번역 시스템을 사용합니다.
레이저 종류(피코, 제네시스, 엑셀V 등), 시술 부위,
주의사항 등 피부과 특화 용어가 정확하게 번역됩니다.
```

**Q3: 시술 가격은 어떻게 설정하나요?**
```
병원에서 자유롭게 가격을 설정합니다.
시술별 정가, 이벤트 가격 등을 직접 관리할 수 있으며,
플랫폼에서 가격을 강제하지 않습니다.
```

**Q4: 입점 후 실제 환자가 올 때까지 얼마나 걸리나요?**
```
다국어 콘텐츠가 검색 엔진에 인덱싱되기까지 통상 2~4주가 소요됩니다.
그 이후부터 검색을 통한 자연 유입이 시작되며,
플랫폼 내 노출을 통해서도 환자 유입이 이루어집니다.
```

# 변형 B — "다국어 SEO" (기회 제공형)

## 개요

| 항목 | 내용 |
|------|------|
| URL | `/lp/b` |
| 타겟 | 외국인 환자를 온라인으로 유치하고 싶은 병원 (구글/검색 노출에 관심) |
| 핵심 메시지 | 입점만 하면 다국어 콘텐츠를 만들어줘서 구글에서 외국인이 우리 병원을 찾게 된다 |
| 타겟 키워드 | `병원 해외 마케팅`, `병원 다국어 홈페이지`, `의료관광 SEO`, `병원 구글 노출`, `외국인 환자 마케팅`, `병원 다국어 콘텐츠` |

---

## UI 톤 & 무드

### 분위기
- **테크 · 글로벌 · 가능성을 보여주는** — "우리 병원이 구글에 이렇게 뜬다고?" 하는 시각적 임팩트
- 브라우저 프레임 안에 검색 결과를 보여주는 것이 핵심
- 깔끔하면서도 약간의 컬러감으로 글로벌/다국어 느낌 표현

### 컬러 팔레트
| 역할 | 색상 | Tailwind | 용도 |
|------|------|----------|------|
| Primary | `#0F172A` | slate-900 | 헤더, 본문 강조 텍스트 |
| Accent | `#6366F1` | indigo-500 | CTA 버튼, 링크, 강조 |
| Accent Soft | `#EEF2FF` | indigo-50 | 섹션 배경, 뱃지 배경 |
| Chinese | `#F59E0B` | amber-500 | 중국어 태그/하이라이트 |
| Japanese | `#EC4899` | pink-500 | 일본어 태그/하이라이트 |
| English | `#3B82F6` | blue-500 | 영어 태그/하이라이트 |
| Surface | `#FFFFFF` | white | 페이지 배경 |
| Card | `#F9FAFB` | gray-50 | 카드 배경 |
| Border | `#E5E7EB` | gray-200 | 카드/구분선 |
| Text Secondary | `#6B7280` | gray-500 | 보조 텍스트 |

### 디자인 원칙
- BrowserFrame을 적극 활용 — 검색 결과, 웹페이지 목업 시연
- 언어별 컬러 태그로 "다국어"를 시각적으로 표현
- 인디고 계열 기반, 깔끔한 카드 UI + 적당한 그림자
- 스크롤 애니메이션: fade-in + 살짝 slide-up 정도
- 라운드: `rounded-xl` ~ `rounded-2xl`

### 3. Before/After 섹션

**배경**: indigo-50

```

- 구글 검색 시 노출 안 됨
- 외국인 환자 유입 경로 없음
- 리뷰/평점 데이터 없음

```

- 구글 검색 1페이지 노출
- 플랫폼 내 글로벌 환자 직접 유입
- 다국어 리뷰 자동 축적

### 7. FAQ 섹션

**배경**: gray-50

**타이틀**: 자주 묻는 질문

**Q1: 다국어 콘텐츠 제작 비용이 정말 무료인가요?**
```
네, 입점 혜택으로 무료 제공됩니다.
중국어, 일본어, 영어 3개 언어의 병원 소개 페이지,
시술 정보 페이지, 의료진 소개 페이지를
SEO 최적화하여 제작해 드립니다.
```

**Q2: 콘텐츠가 실제로 구글 검색에 노출되나요?**
```
네, SEO 최적화된 콘텐츠가 K-BeautyPass 플랫폼을 통해 게시되며,
구글 검색 엔진에 인덱싱됩니다.
"gangnam dermatology", "강남 피부과" 등의 키워드로
외국인 환자가 검색할 때 노출될 수 있습니다.
```

**Q3: 콘텐츠 내용을 수정할 수 있나요?**
```
물론입니다. 초안 제작 후 병원 측 검토를 거쳐
수정 요청이 가능합니다.
시술 추가, 가격 변경, 의료진 변경 등
업데이트도 요청 시 반영됩니다.
```

**Q4: 어떤 언어를 지원하나요?**
```
기본 제작은 중국어(간체), 일본어, 영어 3개 언어입니다.
이 외에도 태국어, 베트남어, 인도네시아어 등
추가 언어 제작이 가능하며, 자동 번역 기능은 12개국어를 지원합니다.
```

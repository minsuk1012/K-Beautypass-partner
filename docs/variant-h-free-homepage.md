## 개요

| 항목 | 내용 |
|------|------|
| URL | `/lp/h` |
| 타겟 | 홈페이지 없이 네이버 플레이스·블로그로 운영해온 의원급 원장 |
| 핵심 메시지 | KBP 입점 병원에게는 다국어 홈페이지 제작이 0원 — 외국인 환자는 구글에서 찾으니까 |

## 타겟 페르소나 & 전략

### 페르소나 — "네이버로 버텨온 원장"
- 의원급 병원, 네이버 플레이스 + 블로그 + 카카오채널로만 운영. 홈페이지 없이도 지금까지 문제없었음
- 과거 제작 견적(수백만 원 + 월 유지비)을 받아보고 "네이버면 충분한데"라며 접은 경험
- 기본 심리: **"홈페이지? 굳이…"** — 랜딩은 "왜 우리 홈페이지가 좋은가"가 아니라 "왜 이제는 필요한가"부터 설득해야 함
- 결정적 빈틈: 네이버는 한국 환자에게만 보임. 외국인 환자는 구글에서 검색

### 전략 확정 사항
- **오퍼 구조**: 입점 혜택형 — KBP 입점 병원 혜택으로 무료 제작을 제시. "예약 성사 시에만 수수료"라는 성과형 구조가 무료의 명분이 되어 의심을 정면 해소
- **유입 채널**: 콜드 검색 유입 기준 설계 (영업 후속 링크로도 그대로 사용)
- **내러티브**: 하이브리드 — 오퍼 선공(검색 의도 매칭) + 구글 공백 스토리 후속(입점 설득)
- **훅 3단 구조**: ① 왜 이제 필요한가(외국인=구글) → ② 왜 0원인가(성과형 구조) → ③ 왜 지금인가(시장 성장 데이터)

**숨은 비용 없음 뱃지 라인**:
```
✅ 입점비 0원   ✅ 제작비 0원   ✅ 월 이용료 0원   ✅ 광고비 0원
```

# 변형 A — "통역 비용 제거" (고통 해결형)

## 개요

| 항목 | 내용 |
|------|------|
| URL | `/lp/a` |
| 타겟 | 외국인 환자를 받고 싶지만 통역 코디 비용이 부담되는 병원 |
| 핵심 메시지 | 통역 코디 없이 AI 자동번역으로 외국인 진료가 가능하다 |
| 타겟 키워드 | `외국인 환자 통역 솔루션`, `병원 자동 번역`, `외국인 진료 통역 비용`, `의료 통역 코디네이터 대체`, `병원 통역 서비스` |

---

## UI 톤 & 무드

### 분위기
- **실용적이고 신뢰감 있는** — 병원 실장이 원장에게 "이거 해봅시다" 보여줄 수 있는 느낌
- 화려한 그라데이션 배제, 숫자와 비교가 중심
- 금융/SaaS 대시보드처럼 깔끔하고 구조적

### 컬러 팔레트
| 역할 | 색상 | Tailwind | 용도 |
|------|------|----------|------|
| Primary | `#1E293B` | slate-800 | 헤더, 본문 강조 텍스트 |
| Accent | `#10B981` | emerald-500 | 절감 금액, 긍정 수치, CTA 버튼 |
| Accent Soft | `#D1FAE5` | emerald-100 | 절감 영역 배경, 뱃지 |
| Danger | `#EF4444` | red-500 | 기존 비용 강조, 취소선 텍스트 |
| Danger Soft | `#FEE2E2` | red-100 | 기존 비용 카드 배경 |
| Surface | `#F8FAFC` | slate-50 | 페이지 배경 |
| Card | `#FFFFFF` | white | 카드 배경 |
| Border | `#E2E8F0` | slate-200 | 카드/테이블 구분선 |
| Text Secondary | `#64748B` | slate-500 | 보조 텍스트 |

### 디자인 원칙
- 블러/그라데이션 효과 최소화 — 깔끔한 라인과 박스 기반
- 취소선(`line-through`) + 빨간색으로 기존 비용을 시각적으로 제거
- 초록색 = 절감/해결, 빨간색 = 기존 비용/문제의 색상 코딩
- 카드에 미세한 그림자(`shadow-sm`)만 사용
- 애니메이션 최소 — 스크롤 시 fade-in 정도만
- 라운드: `rounded-xl` ~ `rounded-2xl`

### 6. FAQ 섹션

**배경**: slate-50

**타이틀**: 자주 묻는 질문

**Q1: AI 번역 품질이 통역 코디만큼 정확한가요?**
```
의료 전문 용어에 최적화된 AI 번역 엔진을 사용합니다.
시술명, 약품명, 주의사항 등 의료 특화 용어 데이터베이스를 기반으로
정확도 높은 번역을 제공하며, 지속적으로 개선하고 있습니다.
```

**Q2: 어떤 언어를 지원하나요?**
```
중국어(간체/번체), 일본어, 영어, 태국어, 베트남어, 인도네시아어,
러시아어, 몽골어, 아랍어, 스페인어, 프랑스어, 독일어 등
12개 주요 언어를 지원합니다.
```

**Q3: 다국어 콘텐츠는 어떻게 제작되나요?**
```
입점 시 병원 정보(시술 목록, 의료진 소개, 위치 등)를 기반으로
전문 번역 + AI 최적화를 통해 다국어 콘텐츠를 제작합니다.
별도 비용 없이 입점 혜택으로 제공됩니다.
```

**Q4: 입점 비용이 정말 무료인가요?**
```
네, 입점비·가입비·연회비 모두 무료입니다.
실제 시술 매출이 발생할 때만 수수료가 부과되는
성과 기반 모델이므로 리스크 없이 시작할 수 있습니다.
```
